## دربارهٔ کتاب

«مبانی معماری نرم‌افزار» (Fundamentals of Software Architecture) از شناخته‌شده‌ترین منابع معماری نرم‌افزار است. ویرایش دوم آن را Mark Richards و Neal Ford نوشته‌اند و O’Reilly در سال ۲۰۲۵ منتشر کرده است. کتاب با نگاهی مهندسی و امروزی، از تفکر معماری، ماژولاریتی و ویژگی‌های معماری آغاز می‌کند. سپس سبک‌های اصلی معماری را یک‌به‌یک بررسی می‌کند: لایه‌ای، تک‌پارچهٔ ماژولار، خط لوله، میکروکرنل، مبتنی بر سرویس، رویدادمحور، مبتنی بر فضا، سرویس‌گرای ارکستراسیون‌محور و میکروسرویس‌ها. بخش پایانی به مهارت‌هایی می‌پردازد که هر معمار به آن‌ها نیاز دارد: تصمیم‌گیری و ثبت تصمیم‌ها، تحلیل ریسک، نمودارکشی، اثربخش کردن تیم‌ها، مذاکره و رهبری.

- **سه قالب:** Markdown، HTML راست‌به‌چپ و PDF، هم برای هر فصل و هم برای کل کتاب.

- **شکل‌ها:** هر ۲۴۱ شکل کتاب در جای خود آمده و عنوان‌هایشان به فارسی ترجمه شده است.

## اصول ترجمه

- **معادل‌گذاری:** هر اصطلاح کلیدی در نخستین کاربرد به‌صورت «معادل فارسی (English Term)» آمده و پس از آن فقط معادل فارسی به کار رفته است. همهٔ معادل‌ها از یک واژه‌نامهٔ مشترک می‌آیند تا در سراسر کتاب یکسان بمانند.
- **نام‌ها:** نام افراد، ابزارها، فریم‌ورک‌ها و محصولات به همان صورت انگلیسی مانده است، مانند Martin Fowler، Kubernetes و DevOps.
- **کد:** قطعه‌کدها، نام توابع و متغیرها، مسیر فایل‌ها و دستورهای ترمینال ترجمه نشده‌اند و چپ‌به‌راست نمایش داده می‌شوند. فرمول‌ها با LaTeX نوشته شده‌اند.
- **نگارش:** رعایت دقیق نیم‌فاصله، پرهیز از مجهول‌سازی ساختگی و گرته‌برداری از ساختار جملهٔ انگلیسی، و وفاداری کامل به معنای متن اصلی.
- **ساختار:** سلسله‌مراتب تیترها، نکته‌ها، جعبه‌های کناری، جدول‌ها و شکل‌ها مطابق کتاب اصلی حفظ شده است.

## ساخت خروجی‌ها

همهٔ خروجی‌ها با اسکریپت‌های Python داخل پوشهٔ `translation/` ساخته می‌شوند:

```bash
cd translation
python3 build_chapter.py 1 01 02 03       # ادغام بسته‌ها در فایل کامل فصل
python3 qa.py                             # کنترل کیفیت (خوش‌ساختی، تطابق MD↔HTML، واژه‌نامه)
python3 build_book.py                     # book.md و book.html

pip install playwright pymupdf && playwright install chromium
python3 build_pdf.py                      # pdf/book.pdf و pdf/chapters/*.pdf
python3 build_pdf.py --chapters 1 15 27   # فقط فصل‌های مشخص (0 = پیوست)
```

جزئیات خط تولید، جدول بسته‌ها و قواعد نگارشی در [`translation/README.md`](translation/README.md) آمده است.
